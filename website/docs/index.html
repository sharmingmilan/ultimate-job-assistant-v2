Conventions you should know

Naming convention

All per-application outputs follow [company]-[role-slug]-[YYYY-MM].[ext]. The orchestrator sets these variables once at the start of each application.

Output folders

Each output type lives in its own folder: resumes/, scores/, cover-letters/, etc. Sort by name in your file manager to group by company.

Research per company, not per role

Every company gets one research/[company].md. Section 1 is reusable across roles; Section 2 has dated subsections per role.

No fabrication

All claims about companies cite a source. All reported interview questions cite a Glassdoor / Blind / Levels.fyi link. If a fact can't be verified, the toolkit refuses to invent one.
