Setup walkthrough

Onboarding

Set up your own personalized version of Ultimate Job Assistant. About 30 to 45 minutes, mostly because memory.md is worth thinking through carefully.

Prerequisites

  • Claude Desktop with Cowork mode (or a compatible Claude environment with file tool access).
  • A folder you control on your Mac or PC where the project will live.
  • Your base resume, ideally as a DOCX.
  • Optional: a GitHub account if you want a private backup.
  • Optional: a free Netlify account if you want to host the interview-prep PWAs.

Step 1: Get the project

git clone https://github.com/<owner>/ultimate-job-assistant-public.git "Ultimate Job Assistant"
cd "Ultimate Job Assistant"

Or download a release zip if you prefer.

Step 2: Personalize memory.md

This is the most important file in the project. It is Claude's primary source for understanding your work style, anchor stories, and resume preferences. Open it and replace each section with your own:

  • Identity and background — name, current city, contact preferences.
  • Career history at a glance — companies, roles, dates, scope.
  • Key stories — three to six anchor stories you'd tell in a behavioral interview, in STAR format.
  • Resume preferences — formatting rules you stand by (e.g., no em-dashes, two-page max, contact line on a single line).
  • What you want next — target role types, industries, company-size preferences.
  • What's off-limits — companies, industries, or work types you've decided against.

Take your time on this file. Ten thoughtful minutes here saves hours of bad output later.

Step 3: Drop in your base resume

base-resumes/[your-role-type].docx

For example: base-resumes/data-analyst.docx. You can have multiple base resumes for different role types.

Step 4: Start a session in Claude

Open Claude Desktop, switch to Cowork mode, select the project folder. Then say:

"I want to apply to [Company] for the [Role] position. Here's the JD: [paste or link]"

Claude reads CLAUDE.md to orient itself, then routes through the orchestrator, which walks you through each step.

Step 5 (optional): Initialize your own private git repo

cd "Ultimate Job Assistant"
git init -b main
git config user.email "you@example.com"
git config user.name "Your Name"
git add -A
git commit -m "Initial: my Ultimate Job Assistant"
git remote add origin git@github.com:youruser/ultimate-job-assistant.git
git push -u origin main

Keep your fork private.

Even with the provided .gitignore excluding personal-data folders, your memory.md and any committed evaluation fixtures may carry information about you that you don't want public. The original author's project follows a two-tier model: private repo holds the personal copy permanently; only this onboarding doc and the public companion repo are ever public.

Step 6 (optional): Hook up Netlify for the interview-prep PWAs

When the interview-prep skill outputs a folder like interview-prep/[company]-[role-slug]-[YYYY-MM]-pwa/, you can deploy it for free in 30 seconds:

  1. Sign up at netlify.com.
  2. Open Netlify Drop.
  3. Drag the folder onto the page.
  4. Get an HTTPS URL.
  5. Add to your iPhone home screen via Safari → Share → Add to Home Screen.

No backend, no database, no monthly cost.

What's safe to share publicly

✓ Yes

  • This onboarding doc
  • SPEC.md, ROADMAP.md, README.md, DESIGN_DOC.md (after sanitization)
  • Skill code under skills/*/ (except eval fixtures with real data)
  • Generic templates and patterns under references/
  • The interview-prep PWA template

✗ No

  • memory.md
  • base-resumes/
  • research/[company].md
  • resumes/, scores/, speaking-points/, cover-letters/
  • Per-application interview-prep/[convention]-pwa/ folders
  • Anything in portfolio/, networking/, applications/, archive/

Troubleshooting

Claude can't find a file
Check that the Cowork folder pick is the project root, not a parent directory. Paths in skill specs are relative to the project root.
The PWA template won't render
Ensure CDN access is allowed (jsDelivr is the default). The build script will tell you if a CDN script failed to load. The PWA also runs offline once the service worker is registered.
A skill produced a bad output
Reject the output, tell Claude what was wrong, and re-run. The orchestrator preserves your prior approvals — only the rejected step re-runs.
The interview-prep skill found "no sourced questions" for my company
That's intentional — the skill refuses to fabricate. Either accept the empty Real Qs tab, or feed the skill a list of questions you found yourself.
