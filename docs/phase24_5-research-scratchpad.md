**Signal — Read.cv is dead.** Perplexity acquired it January 2025 and the platform wound down by May 16, 2025. Users could migrate the `.cv` domain to **Hello.cv** (the successor). For Phase 24.5 this means: profile Hello.cv as the live successor, optionally fetch Read.cv's pre-shutdown UI from the Wayback Machine to preserve the original visual reference.

**Triage:** lock three outliers covering distinct cross-domain shapes:

1. **Are.na** (`are.na`) — visual research / collection tool. "Calm internet" aesthetic. Personal, deliberate, anti-attention-economy. Closest positioning analog to v2 outside the job-search space.
2. **Pinboard** (`pinboard.in`) — minimalist bookmarking service. Anti-SaaS posture, ASCII-tier UI. Single-developer indie tool that explicitly resists scaling. Anti-pattern reference for "what UI density looks like at the extreme minimal end."
3. **Hello.cv** (`hello.cv`) — minimal personal profile / personal-site successor to Read.cv. ".cv" identity-as-personal-site shape. Will reference Wayback Machine for Read.cv pattern as supplementary if Block 2 needs the original aesthetic.

R6 user-review reading is **not required** for outliers per R7's last sentence — the three outlier picks contribute pattern signal, not failure-mode signal.
